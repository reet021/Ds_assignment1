# TOPSIS Assignment

## Objective
To implement the TOPSIS (Technique for Order Preference by Similarity to Ideal Solution) algorithm as a command-line Python program.

## Files
- `topsis.py` : Command-line TOPSIS implementation
- `data.csv` : Input data file
- `result.csv` : Output file with TOPSIS scores and ranks
- `topsis_assignment.ipynb` : Colab notebook demonstrating execution

## Usage
```bash
python topsis.py data.csv "1,1,1,1,1" "+,+,-,+,+" result.csv
